2. Random variables

A random variable is a function $X:\Omega\to\mathbb{R}$. It converts outcomes into numbers.

$$X:\Omega\longrightarrow \mathbb{R}, \qquad \omega \longmapsto X(\omega).$$

Discrete random variable

Possible values are countable: $0,1,2,\ldots$ or a finite list.

Examples: Bernoulli, Binomial, Geometric, Poisson.

Continuous random variable

Possible values lie in intervals. Single points usually have probability zero.

Examples: Uniform, Exponential, Normal, Gamma.

3. Discrete distributions and PMFs

For a discrete random variable, the probability mass function is

$$p_X(x)=P(X=x), \qquad p_X(x)\ge 0, \qquad \sum_x p_X(x)=1.$$

Interactive Binomial distribution

If $X\sim\mathrm{Binomial}(n,p)$, then $X$ counts successes in $n$ independent Bernoulli trials.

$$P(X=k)=\binom{n}{k}p^k(1-p)^{n-k},\qquad k=0,1,\ldots,n.$$

A continuous distribution is described by a probability density function. Probability is area under the density curve, not height at one point.

Density rule

$f_X(x)$ can be larger than $1$. What matters is total area:

$$\int_{-\infty}^{\infty}f_X(x)\,dx=1.$$

CDF rule

$F_X(x)$ is nondecreasing, right-continuous, starts at $0$, and ends at $1$.

For continuous $X$, $f_X(x)=F_X'(x)$ where differentiable.

5. Finding normalizing constants

Many densities are first given up to a constant. The constant is determined by total area $1$.

$$\int_{\text{support}} c\,g(x)\,dx=1 \quad \Longrightarrow \quad c=\frac{1}{\int_{\text{support}}g(x)\,dx}.$$

Example A

$f(x)=c\cos x$, $-\pi/2

Since $\int_{-\infty}^{\infty}e^{-2|x|}\,dx=1$, we need $c=1$.

7. Mixed distribution: a point mass plus a density

Some random variables have both a discrete jump and a continuous part. This is common in insurance, reliability, censoring, and piecewise economic value models.

Example: $T\sim\mathrm{Exponential}(\theta=1.5)$ and

$$V=\begin{cases}5,&T<3,\\2T,&T\ge 3.\end{cases}$$

There is a point mass at $V=5$:

$$P(V=5)=P(T<3)=1-e^{-2}.$$

There is a continuous density for $v\ge 6$:

$$f_V(v)=\frac{1}{3}e^{-v/3},\qquad v\ge 6.$$

The full CDF is

$$F_V(v)=\begin{cases}0,&v<5,\\1-e^{-2},&5\le v<6,\\1-e^{-v/3},&v\ge 6.\end{cases}$$

The flat part between $5$ and $6$ occurs because $V$ cannot take values strictly between $5$ and $6$.

8. Simulation lab: empirical CDF

Simulation helps students see that a distribution is a long-run pattern. Generate samples from $Y$ with $F_Y(y)=1-1/y^2$ for $y\ge1$ using inverse transform sampling.
